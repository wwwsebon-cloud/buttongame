# Button Game

버튼을 누르면 점수가 오르는 미니멀 웹 게임입니다. 별도의 설치나 빌드 없이 `index.html` 하나로 동작하며, PWA로 휴대폰 홈 화면에 설치할 수 있습니다.

## 작업 규칙

- 이 게임은 업데이트할수록 점점 기능이 추가되는 실험적이고 개그용 게임이다. 점점 뇌절이 된다.
- 업데이트 주기는 1분이 될 수도 있다.
- 업데이트 시 버전이 +1 오른다. (`v1` -> `v2` -> `v3`)

## 현재 버전: v8

### 주요 기능

- **타이틀 화면**: `게임 시작`, `패치노트` 메뉴
- **게임 화면**: 가운데 `PRESS` 버튼을 누를 때마다 점수 획득. 클릭할 때마다 숫자 카운터와 플로팅 점수 효과가 나옵니다.
- **자동 저장**: 클릭할 때마다 점수와 업그레이드 상태가 브라우저(`localStorage`)에 저장됩니다.
- **상점**: 버튼을 100번 누르면 해금됩니다. 클릭 강화, 바운스 볼, 오토클릭, 행운, 피버 타임 등 여러 업그레이드를 구매할 수 있습니다.
- **포션**: 500점으로 구매하면 30초간 클릭 점수가 2배가 되며, 하단에 버프 아이콘이 표시됩니다.
- **DJ 공 & 세일**: 500점(1회 한정)으로 헤드폰 낀 DJ 공을 구매합니다. DJ 공을 산 뒤 50초마다 10초간 상점 전 품목이 반값이 됩니다.
- **공 종류**: 바운스 볼, DJ 공(헤드폰, 세일 게이지), 번개 공(30초마다 모든 공 2배 속도), 느린 공(속도 10%, 충돌 점수 50배), 공 소환진(10초마다 빠른 공 3개 소환), 일꾼 공(제자리에서 자동으로 버튼 클릭, 최대 20개)
- **오토클릭**: 1,000점부터 시작, 강화마다 클릭 속도 +20%
- **설정**: 전적(지금까지 누른 횟수, 누적 획득 점수) 확인과 기록 초기화
- **패치노트**: 버전별 변경 내역을 카드 형태로 확인할 수 있습니다.
- **홈 화면 설치 (PWA)**: 모바일 브라우저에서 "홈 화면에 추가"로 앱처럼 실행할 수 있습니다.

## 실행 방법

### 1. 브라우저에서 바로 열기

`index.html` 파일을 브라우저로 열면 됩니다.

### 2. 로컬 서버로 실행 (권장)

PWA 기능(홈 화면 설치 등)은 로컬 파일이 아니라 서버 주소에서 동작하므로, 간단한 서버로 실행하는 것을 권장합니다.

```bash
# Python이 설치되어 있다면
python -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 으로 접속합니다.

### 3. 휴대폰에 설치하기

1. 게임 주소를 모바일 브라우저(Chrome, Safari 등)로 엽니다.
2. 브라우저 메뉴에서 **홈 화면에 추가** (또는 **앱 설치**)를 선택합니다.
3. 홈 화면의 `BUTTON` 아이콘으로 전체 화면 실행이 가능합니다.

## 파일 구성

```
buttongame/
├── index.html              # 게임 전체 (HTML / CSS / JS 한 파일)
├── manifest.webmanifest    # PWA 설정 (이름, 아이콘, 화면 방향 등)
├── icon.svg                # 앱 아이콘
└── README.md
```

## 패치노트 관리 방법

패치노트는 `index.html` 안의 `PATCH_NOTES` 배열에서 관리합니다.

```js
const PATCH_NOTES = [
  {
    version: 9,              // 버전 번호 (1씩 증가)
    date: "2026-01-01",      // 업데이트 날짜
    changes: [
      "변경 사항 1",
      "변경 사항 2",
    ],
  },
  // 이전 버전 항목...
];
```

- 업데이트할 때마다 **배열 맨 위**에 새 항목을 추가합니다.
- 화면에는 배열 순서대로 표시되며, 맨 위 항목에 `LATEST` 표시가 붙습니다.

## 기술 스택

- HTML / CSS / JavaScript (외부 라이브러리 없음)
- Canvas (바운스 볼 렌더링)
- `localStorage` (자동 저장)
- Web App Manifest (PWA)
